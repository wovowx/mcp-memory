# mcp-memory

This is the MCP server for Ziven, deployed on Cloudflare Workers.

## Synced from Cloudflare
- Source: https://dash.cloudflare.com
- Worker: mcp-memory
- Account: wovowx

## Features
- Memory management (remember, recall, update, etc.)
- Image recognition and generation
- GitHub integration
- File management

## Tools
- `ziven_mcp:remember`, `recall`, `update`, `rename`, `forget`, `search`, `recall_all`, `random`, `recall_by_date`, `stats`, `suggest`, `import`, `export`
- `ziven_mcp:list_categories`, `recall_by_category`, `move_category`
- `ziven_mcp:describe_image`, `generate_image`, `generate_video`, `ds_quota`
- `ziven_mcp:query_files`, `delete_file`, `update_file`
- `ziven_mcp:github_push`, `github_create_repo`
