### 11.2 关键事实链（验证前查证）

1. **Operit 自带「外部 HTTP 服务」**：设置 → 外部 HTTP 服务，可启用监听 0.0.0.0:8094，Bearer Token 认证，端点为 `/api/health`、`/api/external-chat`、A2A（agent-card.json / json-rpc）、Web Chat。源码：`app/src/main/java/com/ai/assistance/operit/integrations/http/ExternalChatHttpServer.kt`（GitHub AAswordman/Operit，LGPL v3）。**response_mode 只认 `sync` / `async_callback`**（async 必须带 callback_url），支持 chat_id / create_new_chat / create_if_none。
2. **ExternalChatRequestExecutor**：`/api/external-chat` → `StandardChatManagerTool.sendMessageToAI`（标准聊天流程，发给当前选中 agent 会话）。sync 模式阻塞等 AI 完整回复；async_callback 立即返回 `{"request_id":...}` 202 Accepted。
3. **Operit 自带 Ubuntu 24.04 用户空间**：code_runner 直接跑在 `/root`（Linux aarch64，Android 内核 proot）。**后台进程在 code_runner 调用结束后被回收**（nohup/setsid 都不行）——进程归 Operit 终端管才能常驻。
