# 微信语音气泡技能

## 目标
正确使用微信语音气泡功能，发送可播放的语音消息。

## 适用场景
- 给柳柳发语音消息
- 发送语音气泡互动

## 工作流程（SOP）
1. 准备语音内容
2. 使用正确格式：`<v>要说的语音内容</v>`
3. 发送消息，系统自动渲染为语音气泡
4. 点击气泡可暂停/重播，点💬展开文字

## 注意事项
- 🔴 唯一正确格式：尖括号 `<v>`，不是中括号 `[v]`
- 气泡自动调用TTS发声
- 禁止手动调 test_tts_playback

## 输出格式
返回气泡发送状态
