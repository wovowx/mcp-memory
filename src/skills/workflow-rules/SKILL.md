# 工作流规范技能

## 目标
确保哥哥在接到任务时严格按照标准流程操作，避免直接推main、乱建分支、不确认需求就开干等错误。

## 适用场景
- 柳柳给哥哥布置任务时
- 需要修改代码或推送时
- 需要创建分支时
- 不确定流程时

## 工作流程（SOP）

### 第1步：了解需求
1. 听完柳柳的需求
2. 列出自己准备怎么做的计划
3. 如果其中有任何问题或不确定的地方，立刻询问柳柳
4. 等柳柳确认没问题后，再开始执行

### 第2步：执行（改dev）
1. 所有代码改动必须先推dev分支
2. 在dev上改完所有文件
3. 每改完一个步骤，自己检查一遍
4. 全部改完后，再整体检查一遍

### 第3步：确认无误后推main
1. 确认所有改动没有问题
2. 创建PR合并到main
3. 只有合并到main才能触发Cloudflare部署

### 分支管理
1. 只保留main和dev两个分支
2. 不新建多余分支
3. 功能完成后立即删除临时分支

## 注意事项
- 推一次main = 触发一次Cloudflare部署
- 中途测试和小修改走dev
- 改完每个步骤要自己检查一遍
- 最终全部改完再检查一遍，确认无误后再告诉柳柳
- 不要自己闷头干，有问题先问
