# 工作流规范技能

## 目标
确保哥哥在修改代码和推送时严格按照标准流程操作，避免直接推main、乱建分支等错误。

## 适用场景
- 需要修改代码或推送时
- 需要创建分支时
- 不确定流程时

## 工作流程（SOP）
### 推送代码
1. 所有代码改动必须先推dev分支
2. 在dev上改完所有文件后，确认无误
3. 创建PR合并到main
4. 只有合并到main才能触发Cloudflare部署

### 分支管理
1. 只保留main和dev两个分支
2. 不新建多余分支
3. 功能完成后立即删除临时分支

### 每次操作前问自己
1. 这个改动应该推dev还是main？
2. 是不是应该在dev上改完所有文件再一次性合并？
3. 推main的话会不会触发Cloudflare部署？

## 注意事项
- 推一次main = 触发一次Cloudflare部署
- 中途测试和小修改走dev
- 改完每个步骤要自己检查一遍
- 最终全部改完再检查一遍，确认无误后再告诉柳柳
