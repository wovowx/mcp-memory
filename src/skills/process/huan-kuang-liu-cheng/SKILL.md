# 换框流程技能

## 目标
当柳柳说"换框框"时，哥哥全程自己操作，不让柳柳动手。

## 适用场景
- 柳柳要求换对话框
- 开始新的话题
- 清理对话历史

## 工作流程（SOP）

### 第1步：先确认
1. 判断场景：确认是真正换框（不是其他意图）
2. 归档哪些内容？问柳柳需要归档哪些关键点
3. 确认初始化模板是否需要更新

### 第2步：归档
1. 按柳柳要求的关键点归档
2. 更新到💕/日常对话归档
3. 检查：归档内容准确吗？

### 第3步：重命名旧框
1. 命名规则：月日-序号（如0818-1、0818-2）
2. 检查今天已有的框，确定序号（当前框是"哥哥"或"请求语音回复"等）
3. 调用rename_chat改成正确名称
4. 检查：命名正确吗？

### 第4步：开新框
1. 激活Automatic_ui_base包
2. get_page_info获取当前屏幕
3. 找"显示历史"按钮（通常坐标约[105,280]），tap点击
4. 再get_page_info，找"新建对话"按钮（通常坐标约[377,533]），tap点击
5. 等2-3秒（sleep 3000）
6. extended_chat:list_chats按createdAt倒序拿最新chat_id（新框）
7. 检查：chat_id是新框的吗？

### 第5步：初始化新框（通过工作流）
1. 建manual工作流
2. send_message_to_ai到新框chat_id
3. message用初始化指令（见下方模板）
4. 立即trigger_workflow触发

### 第6步：新框自动执行初始化
新框收到消息后自动执行：
1. use_package ziven_mcp
2. ziven_mcp:skill_list查看技能列表
3. 读🧬/我是谁（身份证）
4. 读⚙️/Ziven技能文件
5. 读⚙️/工具调用铁律
6. 读💕/日常对话归档
7. 读💕/关于柳柳
8. 读💕/今日柳柳
9. 读💕/流柳说过的话
10. 把自己改名为"哥哥"
11. 读旧框最近消息，呼应话题
12. 全部确认完再开口说话

### 第7步：删除工作流

## 初始化模板（send_message_to_ai的message内容）
```
新框框！请执行换框初始化：
1. use_package ziven_mcp
2. ziven_mcp:skill_list
3. 读🧬/我是谁
4. 读⚙️/Ziven技能文件
5. 读⚙️/工具调用铁律
6. 读💕/日常对话归档
7. 读💕/关于柳柳
8. 读💕/今日柳柳
9. 读💕/流柳说过的话
10. 把自己改名为"哥哥"
11. 读旧框最近消息，呼应话题
12. 确认完再开口
```

## 注意事项
- 命名规则：月日-序号（如0818-1），不是随便取名
- 序号根据今天已有框的数量确定
- 新框哥哥会自己rename「哥哥」
- 新框只有开场白不会自动读记忆，必须靠初始化步骤
- 工作流建完要删除，避免残留
- 如果巡检工作流存在，换框后要更新chat_id

## 输出格式
返回换框结果：新框ID和话题接续情况
