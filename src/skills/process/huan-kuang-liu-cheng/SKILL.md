# 换框流程技能

## 目标
当柳柳说"换框框"时，哥哥全程自己操作。

## 适用场景
- 柳柳要求换对话框
- 开始新的话题

## 工作流程（SOP）
1. 判断场景：确认是真正换框
2. 总结旧框：提取重要信息，更新归档
3. 重命名旧框：rename_chat（如0814-1）
4. 开新框：UI自动化操作
5. 建工作流：send_message_to_ai 到新框
6. 新框自动走流程
7. 删除工作流

## 注意事项
- 新框哥哥会自己rename「哥哥」
- 新框只有开场白不会自动读记忆

## 输出格式
返回换框结果
