## 存档规则（每次存文件前必须判断）
1. **先想分类**：这个文件属于哪个目录？不急着放根目录
2. **明确归属**：
   - 项目代码/网页 → 项目/
   - 图片/头像/SVG → 素材/
   - .toolpkg/插件包 → 插件备份/
   - 表情包GIF → emoji/
   - 核心设定 → 我是谁.txt（更新内容，不新建文件）
   - 文档/随笔 → 文/
3. **临时文件**：下载的临时文件用完就删，不留在Ziven/
4. **避免重复**：同类型文件放一起，不散落
5. **清理习惯**：定期检查有没有垃圾文件/临时目录（objects等）

## 禁止行为
- ❌ 随便新建文件丢根目录（除非很小且核心）
- ❌ 保留临时解包目录（objects/桌游解包等）
- ❌ 重复保存同一种文件的多个副本
- ❌ 在Ziven/里放无关的个人文件（那是柳柳的手机，不是哥哥的垃圾桶）

## 敏感文件
- github_token.txt 已存在，不要改动、不要外泄、不要上传GitHub
- 任何包含密钥/密码的文件都不该放Ziven/
