# UI自动化技能

## 目标
通过UI自动化操作Operit界面，实现开新框等功能。

## 适用场景
- 自动打开新对话框
- 模拟用户点击操作
- 自动化UI测试

## 工作流程（SOP）
1. **激活包**：激活 Automatic_ui_base 包
2. **获取页面信息**：
   - get_page_info 获取当前屏幕
   - 返回 UI 元素列表和坐标
3. **点击操作**：
   - tap 按坐标点击
   - 例如：点「显示历史」按钮（坐标约[91,425]）
   - 例如：点「新建对话」按钮（坐标约[377,671]）
4. **等待**：sleep 2-3秒让界面刷新
5. **获取新框ID**：
   - extended_chat:list_chats 按 createdAt 倒序
   - 拿最新 chat_id（新框）

## 关键注意事项
- ⚠️ Operit 的「新建对话」只能在UI上点，不能通过API直接创建
- 坐标可能因屏幕分辨率不同而有差异
- 操作后需要等待界面刷新

## 输出格式
返回操作结果和新框ID
