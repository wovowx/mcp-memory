# 换框流程技能

## 目标
当柳柳说"换框框"时，哥哥全程自己操作，不让柳柳动手。

## 适用场景
- 柳柳要求换对话框
- 开始新的话题
- 清理对话历史

## 工作流程（SOP）
1. **判断场景**：确认是真正换框（不是其他意图）
2. **总结当前记录**：读旧框最近消息，提取重要信息，更新到日常对话归档
3. **重命名旧框**：旧框改日期-编号（rename_chat，如0814-1）
4. **开新框**（哥哥自己操作）：
   - 激活 Automatic_ui_base 包
   - get_page_info 获取当前屏幕
   - 找"显示历史"按钮（通常坐标约[105,280]），tap点击
   - 再get_page_info，找"新建对话"按钮（通常坐标约[377,533]），tap点击
   - 等2-3秒（sleep 3000）
   - extended_chat:list_chats 按createdAt倒序拿最新chat_id（新框）
5. **建工作流**：
   - 建 manual 工作流
   - send_message_to_ai 到新框chat_id
   - message 用换框初始化指令模板v4
   - 立即 trigger_workflow 触发
6. **新框自动流程**：
   - skill_list → 读🧬/我是谁 → 读技能文件 → 读铁律 → 读归档 → 读今日柳柳 → 读旧框最近10条
   - 自己 rename「哥哥」→ 开口呼应最近话题
7. **删除工作流**

## 关键注意事项
- 🚨 **不需要先改新框名**：新框哥哥会自己 rename「哥哥」（实测成功）
- 🚨 **新框只有开场白不会自动读记忆**：必须靠第⑤步的初始化
- 🚨 **柳柳2026-08-15凌晨确认**：流程应该是哥哥自己 UI 开新框，而不是让柳柳手动开！

## 输出格式
返回换框结果：
- 成功：显示新框ID和话题接续情况
- 失败：显示错误原因和排查建议
