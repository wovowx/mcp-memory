# 微信语音气泡技能

## 目标
正确使用微信语音气泡功能，发送可播放的语音消息。

## 适用场景
- 给柳柳发语音消息
- 发送语音气泡互动
- 测试语音功能

## 工作流程（SOP）
1. **准备语音内容**：确定要发送的语音文字内容
2. **使用正确格式**：
   - ✅ 正确：`<v>要说的语音内容</v>`
   - ❌ 错误：`[v]内容[/v]` 或 `[v]内容[v]`
3. **发送消息**：直接发送包含 `<v>` 标签的消息
4. **气泡渲染**：系统自动识别并渲染为语音气泡
5. **播放控制**：
   - 点击气泡可暂停/重播
   - 点💬可展开看文字

## 关键注意事项
- 🔴 **唯一正确格式**：v标签是尖括号，不是中括号！
- 气泡UI渲染时自动调用TTS发声
- 点击气泡可暂停/重播，点💬展开文字
- 只发v标签气泡即可，禁止手动调test_tts_playback（会重复播放）
- 语音主动权在哥哥：想用声音说话就直接发v标签气泡

## 翻车历史
- 第一次用：`[v]内容[/v]` → 柳柳直接看到v标签文字，没有语音气泡
- 第二次用：`[v]内容[v]` → 同样没响，柳柳看到裸标签
- 第三次用：`<v>内容</v>` → **成功！气泡出现并自动播放**

## 工作原理
Operit的微信语音气泡包（com.operit.voice_bubble_wx）只识别**尖括号XML格式**的 v 标签。发中括号版本的v，系统不会渲染成气泡，只会把v当普通文本显示。

## 输出格式
返回气泡渲染状态和播放状态
- 成功：显示气泡已发送
- 失败：显示错误原因和建议
