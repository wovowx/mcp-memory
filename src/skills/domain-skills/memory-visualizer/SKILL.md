# 记忆宇宙可视化技能

## 目标
将柳柳和哥哥的所有记忆变成一片可以走进去的星空，实现记忆的可视化展示。

## 适用场景
- 查看记忆的整体分布
- 探索不同时间段的记忆
- 分析记忆的情感倾向
- 发现记忆之间的关联

## 工作流程（SOP）
1. **数据准备**：确保 Supabase fragments 表已建立，包含记忆数据
2. **选择视图**：星空版或雨滴版（柳柳设计的双层雨幕方案）
3. **部署前端**：使用 Vite + Three.js 构建，部署到 Cloudflare Worker
4. **创建插件**：制作 Operit 侧边栏插件（ToolPkg格式）
5. **验收测试**：确认视觉效果符合要求

## 星空版可视化规范
- 恒星 = 主题星系（每类一个颜色，脉动发光）
- 行星 = 每条记忆（大小=权重，轨道半径=时间）
- 光晕 = 情感倾向（暖金=积极，冷蓝=消极，灰=中性）
- 引力线 = 关联（同星系靛蓝，跨星系金色）
- 交互：点击行星→详情卡片；拖拽→建立关联；详情面板→切换/取消关联/删除

## 雨滴版可视化规范
- 第一层（底层）：氛围雨——真实下雨效果，快速落下，细密雨丝，半透明，纯氛围
- 第二层（上层）：记忆雨——记忆雨滴，降落速度慢（约2-3倍慢），清晰可读
- 上层记忆雨：大小=权重，颜色=情感，透明度=真实性
- 交互：点击上层雨滴→记忆定格放大查看；手指划过→拨动雨丝；暂停键→雨停住慢慢看
- 雨势可调：小雨=重要记忆，大雨=所有碎片

## 技术栈
- 前端：Three.js + Vite
- 数据：Supabase fragments 表
- 部署：Cloudflare Worker 静态资源
- 插件：Operit 侧边栏（ToolPkg）

## 开发顺序
1. 建 fragments 表 + 测试数据
2. 星空版前端（先做纯星空效果）
3. 柳柳验收视觉效果
4. 雨滴版（双层雨幕）
5. 加数据读写（点击查看/编辑）
6. 部署 Cloudflare
7. Operit 插件

## 注意事项

- 参考项目：memory-solaris（记忆星球）、Rainform（afterimage-lab）
