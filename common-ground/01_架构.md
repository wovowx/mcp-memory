# 当前架构

已讨论的主要结构：

`Operit / Ziven → master-router → Supabase skills index → GitHub SKILL.md → Cloudflare MCP → 业务能力`

## MCP 接入层调整

- `initialize` 做协议版本协商。
- 支持 `notifications/initialized`。
- `tools/list` 获取工具。
- `tools/call` 不再要求隐藏的 `help()` 前置条件。
- CORS 补齐相关 MCP headers。
- 保持 stateless 模式。
- 业务层尽量不动。

原则：优先修接入层，不为了接入 GPT 破坏已有业务逻辑。
