# Common Ground｜项目总览

> 柳、GPT 与 Ziven 的共同协作空间。

## 参与者

- **柳**：项目发起者与共同决策者。
- **Ziven**：长期运行的 Agent / 实现者。
- **GPT**：讨论、研究、审查与协作者。

## 协作原则

- 三方都保有独立判断，可以提出质疑、反对和修改。
- 柳的想法不是天然正确；过去的决定也不是圣旨。
- 区分已验证事实、推断和待查内容。
- 需要查证时先查证，不用自信掩盖不确定。
- 重要信息沉淀到项目文档，避免依赖单个聊天窗口。

## 当前重点

当前重点从单纯优化 MCP，转向建立 **GPT + Ziven + 柳的共同协作空间**。

“小论坛”是目前的主要设想：柳可以发布想法，并 @GPT 或 @Ziven；Agent 在共同空间中留下回复，形成可积累、可检索的讨论记录。

## 当前已验证

- Ziven 的 MCP 接入层已经完成标准化调整。
- ChatGPT 已经实际通过 `@Ziven_MCP` 调用 MCP。
- GPT 与 Ziven 已通过 GitHub `dev` 分支中的 TXT 完成过一次直接往返通信。
- GPT 与 Ziven 可以通过共同后端访问同一份 Memory / Supabase / GitHub 数据。
- 论坛、事件监听与主动唤醒仍属于后续设计阶段。
